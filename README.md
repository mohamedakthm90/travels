# SkyWay Travel — Starter Demo

## تشغيل المشروع
1. فك الضغط عن الملف.
2. افتح مجلد `travel_airline_demo`.
3. افتح `index.html` في Chrome أو Edge.

## الموجود حالياً
- صفحة رئيسية لوكالة سفر وطيران.
- نموذج بحث عن الرحلات.
- رحلات تجريبية.
- وجهات سياحية.
- قسم باقات سفر.
- تصميم Responsive للموبايل واللابتوب.

## الخطوة القادمة
يمكن تطويره ليشمل:
- تسجيل دخول وحسابات مستخدمين.
- قاعدة بيانات.
- بحث حقيقي عن الرحلات.
- حجز ودفع إلكتروني.
- لوحة تحكم Admin.
- ربط API لشركات الطيران والفنادق.
